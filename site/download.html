Pobierz Modo CMS

Czyste archiwum bez bazy danych, uploadów i plików deweloperskich. Rozpakuj, uruchom kreatora i masz gotową stronę na PHP 8 i SQLite3.

Wymagania

Co jest potrzebne

  • PHP 8.0 lub nowszy
  • Rozszerzenia pdo_sqlite, sqlite3 i mbstring
  • Apache, Nginx lub wbudowany serwer PHP
  • Prawo zapisu do katalogów data/ i uploads/
  • Żadnego zewnętrznego serwera bazy danych
bash
# 1. pobierz projekt $ git clone https://github.com/multicolor-rgb/ModoCMS.git # 2. prawa zapisu (Apache/nginx: www-data) $ chmod -R 775 ModoCMS/data ModoCMS/uploads # 3. otwórz kreatora instalacji $ open http://localhost/ModoCMS/install.php
Szybki start

Od zera do działającej strony w minutę

01

Rozpakuj archiwum

Wrzuć pliki do katalogu głównego lub podkatalogu na serwerze.

02

Nadaj prawa zapisu

Katalogi data/ i uploads/ muszą być zapisywalne przez użytkownika serwera WWW.

03

Uruchom kreatora

Otwórz /install.php, przejdź przez kreator i usuń plik instalatora.
